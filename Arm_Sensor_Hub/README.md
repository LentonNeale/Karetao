# Arm Sensor Hub

STM32F405RGT6 firmware project generated with STM32CubeMX and built with CMake.

## Documentation

Karetao system-level requirements, interfaces, architecture and integration authority are maintained under [`Documentation/`](../Documentation/).

This repository's implementation documentation remains authoritative for Arm Sensor Hub implementation details, component configuration, diagnostics and component-level verification.

## Build

    cd Arm_Sensor_Hub
    cmake --preset Debug
    cmake --build --preset Debug
