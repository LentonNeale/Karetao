# SD-25 — Independent safety mechanisms

**Status:** MODIFIED

## Summary

Independent E-stop, motor-disable/power-removal path, watchdog, stop/brake behaviour, fault indication, reset behaviour, and applicable safety-rated architecture are release gates.

## Open Issue / Comment

The boundary and interface between Karetao application controls and the independent safety system must be explicitly defined by the machine risk assessment and safety architecture.
