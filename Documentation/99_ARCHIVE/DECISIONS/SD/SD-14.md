# SD-14 — Required command interface

**Status:** MODIFIED

## Summary

Commissioned position/velocity plus enable, disable, and controlled-stop operations; heartbeat, lifecycle, calibration, and safety gating required.

## Open Issue / Comment

Define command acknowledgement, freshness, timeout, cancellation, and the distinction between application controlled-stop and independent emergency stop.
