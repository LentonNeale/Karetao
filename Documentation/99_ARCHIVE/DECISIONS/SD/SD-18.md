# SD-18 — Timestamp accuracy

**Status:** APPROVED

## Summary

Target timestamp error ≤ ±1 ms relative to shared STM32/Pi time model; expose sync validity and age.

## Open Issue / Comment

Validate whether ±1 ms is sufficient for the 500 Hz EKF and downstream control requirements.
