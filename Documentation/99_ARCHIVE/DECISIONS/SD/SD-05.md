# SD-05 — CAN network requirements

**Status:** MODIFIED

## Summary

1 Mbps nominal v1 target, standard 11-bit IDs, <50–60% measured average load target; exact hardware and timing require validation.

## Open Issue / Comment

Exact MKS controller model, firmware, command semantics, feedback semantics, acknowledgement behaviour, brake behaviour, and CAN physical configuration remain open until target-hardware evidence is recorded.
