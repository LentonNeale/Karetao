# SD-20 — Loss of time synchronization

**Status:** MODIFIED

## Summary

Continue acquisition/diagnostics but inhibit time-dependent motion until synchronization returns.

## Open Issue / Comment

Define precisely which downstream operations are time-dependent motion and ensure the motion-permission layer enforces this consistently.
