# SD-09 — Measurement history ownership

**Status:** APPROVED

## Summary

Raspberry Pi/EKF owns measurement queues and estimator history; STM32 provides bounded latest-value caches and coherent records.

## Open Issue / Comment

The 500 Hz EKF setting requires explicit definition of how latest-value records, asynchronous sensor updates, timestamp age, and interpolation/hold behaviour are handled.
