# SD-04 — Motor feedback/command timeout

**Status:** APPROVED

## Summary

Five times the commissioned feedback period; one miss degraded; three consecutive misses inhibit the motor and escalate to FAULT.

## Open Issue / Comment

This primarily addresses feedback/timeout behaviour. Command acknowledgement must be distinguished from feedback freshness.
