# SD-02 — System-wide failure classification

**Status:** MODIFIED

## Summary

Four response levels: INFORMATIONAL, DEGRADED, FAULT, SAFETY_CRITICAL; PL/SIL determined by machine risk assessment.

## Open Issue / Comment

The classification must be mapped to explicit motion-inhibit behaviour and ownership. A fault classification alone does not define who has final authority to prevent motion.
