# SD-12 — Authoritative angle representation

**Status:** MODIFIED

## Summary

Calibrated radians are authoritative at host/API; wire-schema change must be explicitly versioned rather than silently replacing millidegrees.

## Open Issue / Comment

Migration requires a defined schema version, conversion rules, Pi decoder update, and verification evidence before the existing wire field changes meaning.
