# SD-08 — Motor/joint temporal alignment

**Status:** APPROVED

## Summary

Observation skew below 5 ms normally, target below 1 ms for dynamic joints; retain acquisition timestamps.

## Open Issue / Comment

The approximately 46 ms six-axis sweep must be reconciled with estimator/control requirements. Timestamp compensation does not by itself establish that the resulting state update rate is acceptable.
