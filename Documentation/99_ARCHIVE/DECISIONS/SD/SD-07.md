# SD-07 — Joint/motor mapping

**Status:** APPROVED

## Summary

Versioned deterministic logical-joint, sensor-ID, motor/CAN-ID mapping including direction, zero offset, and transmission ratio.

## Open Issue / Comment

The ordinary one-to-one mapping is insufficient for the differential end effector. SD-26 defines the separate motor-to-end-effector-DOF mapping decision.
