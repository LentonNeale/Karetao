# SD-15 — Fixed SPI transaction

**Status:** APPROVED

## Summary

512-byte frame, 490-byte maximum payload, SPI Mode 0, little-endian fields, CRC-32/ISO-HDLC, deterministic request/response ownership.

## Open Issue / Comment

Protocol sizing is defined, but the 5 MHz operating point remains an empirical integration limit until live Pi/STM32 and physical-layer evidence is accepted.
