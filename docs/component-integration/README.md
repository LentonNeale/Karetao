# Component Integration

This area will contain system-level views of component integration.

For each participating component, the system documentation should identify:

- the component repository and owner;
- applicable Karetao requirements;
- system interfaces and timing obligations;
- integration assumptions and dependencies;
- required verification evidence;
- links to the component implementation documentation.

### Component authorities

- Arm Sensor Hub: `LentonNeale/Arm_Sensor_Hub`
- Raspberry Sensor Hub: `LentonNeale/Raspberry_Sensor_Hub`

This area does not become an implementation-documentation mirror of either component repository.
