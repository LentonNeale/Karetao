# SD-03 — Raspberry Pi communication loss

**Status:** APPROVED

## Summary

500 ms heartbeat timeout; reject motion, controlled stop if possible, then motor disable; never hold the last motion command.

## Open Issue / Comment

Controlled stop and motor disable require measurable fault-to-safe-state timing. The exact stop-time requirement remains a system/safety validation item.
