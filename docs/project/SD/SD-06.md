# SD-06 — CAN bus failure

**Status:** APPROVED

## Summary

Detect bus-off, inhibit commands, perform bounded recovery, escalate after repeated failure, and require explicit reactivation.

## Open Issue / Comment

Confirm whether a CAN failure affecting one motor requires a joint-level stop or whole-system stop. Final scope follows the machine risk assessment.
