# SD-23 — Transient vs persistent fault recovery

**Status:** APPROVED

## Summary

Bounded service-specific retries; persistent/repeated/freshness failures enter ERROR and recover to INACTIVE.

## Open Issue / Comment

Define system-level escalation when a subsystem is recovering but motion cannot be considered safe. Recovery must not race with motion permission.
