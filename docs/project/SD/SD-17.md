# SD-17 — SPI host transaction strategy

**Status:** APPROVED

## Summary

DATA_READY interrupt for latency plus configurable polling, initially 1 ms, for recovery; Pi remains SPI clock master.

## Open Issue / Comment

Current Pi baseline does not have a physical DATA_READY GPIO assigned. Until one is assigned and tested, the 1 ms polling path is the available host notification mechanism.
