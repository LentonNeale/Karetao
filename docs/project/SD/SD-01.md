# SD-01 — System timing

**Status:** MODIFIED

## Summary

100 Hz remains the baseline for sensor/state publication and the initial control loop. The EKF update rate is currently set to 500 Hz and will be adjusted if required by downstream system constraints. SPI remains at a 5 MHz initial maximum, subject to validation.

## Open Issue / Comment

The current six-axis physical sweep is approximately 46 ms. The 500 Hz EKF rate therefore requires the estimator to operate from timestamped/latest-value data rather than implying a 500 Hz complete six-axis sweep. End-to-end EKF data availability and latency remain integration items.
